Icon 图标

#

基于 Remix Icon 字体，name 填图标名（不带 ri- 前缀），完整图标列表见 remixicon.com。

展示

示例代码
HTML
<ld-icon name="search-line"></ld-icon>
<ld-icon name="heart-line" size="20" color="#d54941"></ld-icon>
<ld-icon name="star-fill" size="24" color="#e37318"></ld-icon>
<ld-icon name="search-line"></ld-icon>
<ld-icon name="heart-line" size="20" color="#d54941"></ld-icon>

输入参数

属性类型默认值说明
namestring''图标名称（Remix Icon，不带 ri- 前缀）
sizestring''尺寸，纯数字自动补 px，默认继承字体大小
colorstring''颜色，默认继承文本颜色

Lit 批量属性绑定可使用本库 spread 指令，写法为 html`<ld-button ${spread(props)}>保存</ld-button>`。它作用于宿主元素；内部原生控件仅透传文档列出的属性。完整绑定规则见 README。

展示

示例代码
HTML
<ld-date-picker id="date-range" style="width: 320px" range clearable></ld-date-picker>

<ld-date-picker style="width: 320px" range value="2026-10-01,2026-10-07" disabled></ld-date-picker>

尚未选择区间

picker.range = true;
picker.value = ['2026-10-26', '2026-11-05'];
picker.addEventListener('ld-change', (event) => console.log(event.detail.value));

输入参数

clearablebooleanfalse可清空

事件

事件detail 格式说明
ld-change{ value }单日选中或区间选择完成时触发；清空单日返回 ''，清空区间返回 []

面板支持年/月切换、上下月补位日期点选、今天高亮与「今天」快捷键。

深色模式

#

令牌分浅色与深色两套，给 <html> 或任意祖先容器加上 data-ld-theme="dark" 即可整体换肤，无需改动任何组件用法。

展示

切换深色模式
示例代码
HTML
<ld-button variant="primary" onclick="document.documentElement.dataset.ldTheme = document.documentElement.dataset.ldTheme === 'dark' ? '' : 'dark'">切换深色模式</ld-button>
<html data-ld-theme="dark">
  ...
</html>

// 运行时切换
document.documentElement.dataset.ldTheme = 'dark';

令牌速查

类别示例说明
色阶--ld-brand-color-1 ~ 10品牌 / 警告 / 错误 / 成功各 10 级，中性灰 14 级
语义色--ld-brand-color、--ld-bg-color-container、--ld-text-color-primary随主题切换自动变化
尺寸--ld-size-1 ~ 16、--ld-height-s/m/l2 / 4 / 6 … 72 的尺寸阶与控件高度
圆角--ld-radius-default、--ld-radius-medium、--ld-radius-round2 / 3 / 6 / 9 / 12 / 999
字阶--ld-font-size-body-medium、--ld-line-height-title-medium正文字号与行高成对提供
阴影--ld-shadow-1 ~ 3三级，每级三层叠加
