快速开始

组件基于 Web Components（Lit 3 + Light DOM），样式为全局 CSS，按需覆盖 CSS 变量即可定制主题。

<link rel="stylesheet" href="yixi-lit.css" />
<script type="module" src="yixi-lit.js"></script>

<ld-button variant="primary">按钮</ld-button>

事件统一以 ld- 开头（如 ld-change），通过 addEventListener 监听，detail 携带数据。主题变量见 src/styles/tokens.css。

插槽按 Shadow DOM 的习惯书写。组件用 Light DOM 渲染，浏览器不会自动投影 <slot>，基类会在渲染后把内容搬进模板里对应的插槽，具名插槽写 slot="名称" 即可。

<ld-card title="标题">
  <p>正文</p>
  <div slot="footer"><ld-button variant="primary">确定</ld-button></div>
</ld-card>

Message 全局提示

纯 JS API，无需写标签。从模块导入 message 或 showMessage。

深色模式

令牌分浅色与深色两套，给 <html> 或任意祖先容器加上 data-ld-theme="dark" 即可整体换肤，无需改动任何组件用法。

切换深色模式 
<html data-ld-theme="dark">
  ...
</html>

// 运行时切换
document.documentElement.dataset.ldTheme = 'dark';
