# 2026-11-11 CSS 按需加载改造 · 第一步（图标字体剥离）

## 背景

调研结论（详见当日对话）：CSS 没有真正的 tree-shaking，业界按需靠 JS 模块图。本项目 184KB 全量 CSS 中 145KB（3074 个图标类）是 remixicon 字体全集，且 `src/components/icon/style.css` 引着它、20 个组件又引 icon/style.css，导致任何按需引入都拖上图标全集。

## 本次改动（第 1 步 / 共 4 步）

- `src/components/icon/style.css`：删除 `@import remixicon.css`（核心一行，全部组件自动瘦身）
- 新增 `src/styles/icons.css`：图标可选入口，按需用户显式引入
- `src/styles/index.css`：remixicon 改为引 `./icons.css`（等价，职责清晰）
- `src/all.ts`：顶部加 `import "./styles/icons.css"`。**关键坑：浏览器全量包的样式来自组件 auto.js 链而非 styles/index.css，不补这句全量包会丢图标和字体文件**（实测踩过：index.css 掉到 64KB 且无 @font-face）
- `package.json` exports 加 `./styles/icons.css`（放在 `./styles/*.css` 通配之前）
- README（特性/按需说明/构建配置/目录结构四处）与 docs/index.html 补充图标单独引入说明
- `scripts/test-tree-shaking.mjs`：button 按需断言反转为「不含 @font-face/.ri-、不 emit 字体」，新增 icons.css 正向用例（含字体），full 断言含 @font-face，consumer.ts 类型检查加 icons.css import

## 验证结果

- 按需 button：CSS 18,899B raw / 3,715B gzip（此前约 152KB raw 含图标）
- 全量 dist/browser/index.css 188KB 完整（@font-face、.ri- 类、woff2/ttf 齐全）
- test:tree-shaking / browser-build（38 元素 226 属性）/ native-props / formatter-lsp / typecheck / lint 全绿
- 无头 Chrome 截图 demo 页：图标、组件样式、布局正常，服务器日志确认 woff2 请求 200
- rspack 2 个警告均为 TTF 超 300KB 体积提示（图标字体固有问题，第 2 步解决）
