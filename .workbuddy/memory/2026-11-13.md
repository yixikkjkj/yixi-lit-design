# 2026-11-13

## 浏览器基线决策（承接 @layer 担忧）

yixi 担心旧浏览器丢样式，量化后确认并决定采用 A 方案：接受现有基线，不做双产物。

- 技术后果：不支持 @layer 的引擎整段丢弃层块，库 CSS 归零、且无任何控制台报错；使用方自己的未分层 CSS 仍生效（唯一缓冲）。
- 增量其实很小：代码里 `inset`(Chrome 87)、flex `gap`(84)、`:focus-visible`(86/Safari 15.4) 已经把地板抬到 Chrome 86 / Firefox 85 / **Safari 15.4**，@layer 只把 Chrome 推到 99、Firefox 推到 97，Safari 零变化。
- 真实风险窗口是 Chrome 80–98：Lit 能跑、事件正常、样式全丢，比"完全打不开"更糟（看起来像产品故障）。
- 人群侧：caniuse 支持率 96.89%（约 3.1% 不支持），其中 Opera Mini / KaiOS 等本就不跑 Lit；国内桌面 360（Chromium 132+）、QQ（138+）极速模式无风险，360 的 IE 兼容模式本就无法运行 Web Components。
- 结论：基线写在 README 第 176 行即可，不引入 legacy 产物（双份 CSS 的长期一致性维护成本大于收益）。

## 第四步：CSS 裁剪断言细化

### 改动

`scripts/test-tree-shaking.mjs` 新增：

- `buildProbeIndex()`：从 `src/styles/<组件>.css` 派生「只属于一个组件样式文件的类名」，跳过 tokens/base/common/index/icons/layers；29 个组件中 27 个有独占探针（icon 的 `.ld-icon` 被多个文件引用、password-input 无独立样式文件，故无探针）。
- `assertCssFollowsGraph()`：把「JS 模块图」与「CSS 产物」双向对齐。正向——进入 `activeComponents` 的组件，其探针必须出现在 CSS 里（漏 `@import` 会暴露）；负向——未进入模块图的组件，其独占类名一个都不许出现。
- `assertSharedCssOnce()`：`:root{`、`data-ld-theme` 各只允许 1 次，`@layer ld-x{` 块必须正好 3 个 → 拦「公共样式未去重」。注意不能用 `--ld-brand-color:` 计数（`:root` 与深色块各定义一次，天然是 2）。
- 体积闸门：单组件 CSS < 24000 字节（当前 18990，留约 26%），三组件 CSS < 单组件 × 2（当前 24209 vs 18990）。
- 桥接文件体检：遍历 `dist/components/*/style.css`，断言无 `@font-face/remixicon/.ri-`，且每条 `@import` 目标真实存在（改名后静默失效的防线）。
- `finally` 里的 `rm` 加重试并把失败降级为 warn：原本 Windows 上句柄未释放会抛 EPERM，把真正的断言错误替换成清理异常（同时留下 `.tree-shaking-test-*` 残留，本次清掉 1 个）。

### 踩到的坑（关键）

探针类名正则最初写成 `/\.ld-[a-z0-9-]+/`，遇到 BEM 下划线截断，`.ld-dialog__mask` 被取成 `.ld-dialog`；而产物里 `.ld-dialog` 永远后接 `__`，边界断言 `(?![\w-])` 正确地拒绝了它，导致 anchor/back-top/breadcrumb/dialog/pagination/tabs 六个组件全部误报「样式缺失」。这 6 个的共同点是基类写在标签选择器上（Light DOM 直接选 `ld-dialog`），内部元素才用 BEM 类名。修正为 `/\.ld-[a-z0-9_-]+/` 后通过。

### 验证

- 双向反向验证：往 `dist/components/button/style.css` 注入 `@import "../../styles/select.css"` → 报「single component: 未引入组件的样式泄漏」；摘掉 select 桥接里的自身样式 → 报「two components: 组件已打包但样式缺失」。两处产物已还原。
- 五套测试全绿：tree-shaking、browser-build（38 元素 228 属性）、native-props（45 项）、cascade-layers、formatter-lsp；typecheck、lint 0 warning 0 error。
- 体积未变：单组件 CSS 18990 字节 / 3765 gzip，全量 64294 / 9540。
